# Report Card Generator

A simple Java + Swing application that generates report cards without any external dependencies.

## Features

- Input student details and subject marks
- Calculate total, average, and grade
- Generate formatted report card with GPA display

## Requirements

- Java 8 or higher

## Quick Start

**Windows:**
```
Double-click compile.bat
Double-click run.bat
```

**Linux/Mac:**
```
./compile.sh
./run.sh
```

Or compile and run manually:

```bash
# Compile
javac -d bin src/main/java/com/reportcard/*.java

# Run
java -cp bin com.reportcard.Main
```

## Usage

1. Enter **Student ID** and **Name**
2. Add **Subjects** with marks
3. Click **Generate Report** to view the formatted report card
4. Click **Clear All** to reset

## Grading Scale

- **A**: 90-100
- **B**: 80-89
- **C**: 70-79
- **D**: 60-69
- **F**: Below 60
